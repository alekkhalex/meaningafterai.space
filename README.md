# meaningafterai.space

Сайт эссе «Жить на своей волне» Алексея Хламова: ответ на вопрос о смысле жизни в мире, где работу делают машины.

Статическая страница без сборки: `index.html`. Публикуется через GitHub Pages на домене meaningafterai.space.

Локальный просмотр:

```bash
python3 -m http.server 8777
```
